Events notify your application when specific actions occur within LiveLike. When a subscribed event triggers, LiveLike automatically sends a payload to your configured delivery channel so you can automate workflows or process data.

We currently support the two delivery channels listed below.&#x20;

1. Webhook
2. AWS SQS

If you require support for a different channel, please reach out to LiveLike support.
