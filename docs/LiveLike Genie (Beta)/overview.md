## 1. Introduction

LiveLike Genie is an AI-powered assistant integrated into the Producer CRM. It enables producers, engineers, and account teams to create, manage, and learn through a conversational, chat-like interface. Genie helps you move faster by handling complex workflows using natural language commands.

## 3. Supported Widget Types

### Polls

**Text Polls**

* Single question
* Multiple text options
* Custom scheduling

**Image Polls**

* Visual answer options
* Image upload support
* Customizable layouts

### Predictions

**Text Predictions**

* Future event predictions
* Multiple outcomes
* Result tracking

**Image Predictions**

* Image-based outcomes
* Custom attributes
* Visual presentation

**Prediction Follow-ups**

* Result announcements
* Winner celebrations
* Engagement tracking

### Quizzes

**Text Quizzes**

* Multiple-choice questions
* Correct answer marking
* Score tracking

**Image Quizzes**

* Image-based questions
* Visual answer options
* Custom scoring logic
  <br />

### Interactive Widgets

**Emoji Sliders**

* Emotion-based voting
* Customizable scale
* Real-time results
  <br />

## 5. Access & Enablement

### Prerequisites

* Access to LiveLike Producer Dashboard
* At least one live application
* Appropriate user permissions
  <br />

### How to Enable Genie

* Contact your Account Manager
* Email [support@livelike.com](mailto:support@livelike.com)
* Navigate to:
  * Producer Suite → Business Tools → Genie
    <br />

## 7. Feedback & Improvements

### How to Provide Feedback

1. Use the 👍 / 👎 buttons
2. Select a feedback reason
3. Enter your message:
   1. Type feedback: [your message]
4. Click Submit
   <br />

## 8. Best Practices

### Clear Communication

* Use specific, explicit instructions
* Provide all required details
* Confirm important actions before publishing
  <br />

### Efficient Operations

* Use batch operations when possible
* Double-check schedules and time zones
* Review widgets before publishing
  <br />

### Resource Management

* Organize programs clearly
* Choose appropriate widget types
* Maintain consistent naming conventions
