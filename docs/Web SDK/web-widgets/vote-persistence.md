Vote Persistence has been added to Livelike Widgets
When user votes on any widget and comes back, his vote will be remembered and will be shown in the widget

##Quiz Widgets
Quiz widgets accepts only one answer and hence if user has voted once, they cannot submit their answers again for quiz

##Slider Widgets
Slider Widgets accepts only one response for a user. Once the vote is locked user cannot re submit their answers for the same

##Prediction Widgets
User can change their selection for prediction widgets until follow up is published. Once follow up is published, predictions are locked

##Polls
User can keep changing their selection for poll widgets and the same should reflect in the poll percentage

##Cheer Meter
Cheer Meter will show persisted vote count for the widget and when user visits the page again, they can cheer again on the same widget
