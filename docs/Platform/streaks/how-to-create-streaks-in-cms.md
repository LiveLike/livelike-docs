Configure  Periodic Streak setting

On the Periodic Streak setting page, enter the following details:

Streak Name – e.g., “ Prediction streak”

Description (optional) – Brief summary of the quest’s purpose.

Streak Action – Select a User action that will trigger the streak

Streak Threshold - Action Threshold for streak progress  
Start Time and End Time

Period: You can select any of threeDaily, Weekly or Monthly  

Timezone - select timezone

User Group - You can select all or if you want you can target the select user Group  

Click on continue  

Now you'll come to Milestone Rewards page  
here configure milestone rewards, enter the following details:  
Milestone
Streak Length- Select a streak length a user needs to reach for getting the assigned reward  
Recurring   - select this check box to Reward users at multiples of this Streak length (e.g., length 3 rewards at 3, 6, 9, 12...)  
Reward Iteam - Select a reward item

Item Amount - enter the reward amount , Only positive integers are allowed

To add more rewards, click + Add rewards and repeat the steps.

Repeat on Reset - Toggle to allow or prevent users from earning this reward multiple times across streak resets.

To add another milestone, click + Add milestone and repeat the steps.

Click Publish
