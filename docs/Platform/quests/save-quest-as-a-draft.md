### Overview

The **Save as Draft** feature lets producers save quests that are partially configured, so they can return later to complete and publish them.  
This gives teams the flexibility to start quest setup early, without waiting for every detail to be finalized.

***

### Quest Creation Flow

The new quest creation UI includes **two primary buttons** visible across all steps:

| **Button**   | **Description**                                                                                                                                          |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Continue** | Validates required fields on the current step (Basic Settings, Objectives, or Rewards). You can only proceed if all validations pass.                    |
| **Quit**     | Opens a modal with two options:<br />• **Save & Exit** — saves the quest as a **draft**.<br />• **Exit Without Saving** — exits without saving progress. |

***

### Draft-Specific Behavior

| **Behavior**           | **Description**                                                                                                              |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **Minimum validation** | Only **Quest Name** is required to save as draft.                                                                            |
| **When you can save**  | You can save and exit from **any step** — Basic Settings, Objectives, or Rewards.                                            |
| **Editable**           | All quest fields remain editable while the quest is in **Draft** state.                                                      |
| **Visibility**         | Draft quests are **not visible** to end users in feeds or profiles.                                                          |
| **Publishing**         | Once all required details are filled, click **Publish** (available on the Rewards step) to validate and make the quest live. |
| **Status label**       | Draft quests appear under the **Draft tab** on the Quest List page.                                                          |

***

### Example Flow

1. Start creating a quest and enter at least a **Quest Name**.
2. Click **Quit → Save & Exit** to save as a draft.
3. Access the draft later from the **Draft tab** on the Quest List page.
4. Edit and complete any missing details.
5. Click **Publish** on the Rewards step to take the quest live.

***

### Benefits

✅ **Flexible workflow** – Create and refine over time  
🔄 **Collaborative editing** – Different teams can contribute asynchronously  
🧘 **Reduced last-minute stress** – No rush to finalize everything before launch  
🚀 **Faster go-live** – Prepare, review, and publish efficiently
