Each game has its own page, and each release that changes something you can see or configure gets its own entry underneath it.

## How to read these notes

Every release note opens with a coloured banner telling you whether it needs anything from you:

<Callout icon="👍" theme="okay">
  ### Nothing breaks by default

  Upgrade and carry on. New text ships with built-in English wording, and new colour settings fall back to colours you already have.
</Callout>

<Callout icon="📘" theme="info">
  ### Optional to configure

  Something new can be customised, but it works without you touching it.
</Callout>

<Callout icon="🚧" theme="warn">
  ### Check this if it applies

  Usually means custom CSS, or a setting that behaves differently than before. Skip it if you use the game as-is.
</Callout>

If a release has no banner asking for action, there is nothing for you to do.

## What the version numbers mean

Versions look like `1.11.0`.

| Part          | Changes when                                                  | What it means for you                         |
| ------------- | ------------------------------------------------------------- | --------------------------------------------- |
| First number  | Something changes in a way that could break an existing setup | Read the notes before upgrading               |
| Middle number | A feature is added or a screen changes                        | Worth reading. Usually optional to configure. |
| Last number   | A bug is fixed                                                | Nothing to do                                 |

Ask the Arcade team. If you are reporting something that changed unexpectedly, include the game, the version you moved from and to, and where you have the game embedded.
