Spin The Wheel is a luck-based reward game that allows users to spin a customizable prize wheel. You can configure spin types, rewards, visuals, and engagement frequency — making it a flexible retention tool for events, onboarding, and daily rewards.

***

**The STW setup consists of 6 key steps as outlined below:**

1. \*\*Welcome & Information Screen \*\*

   1. Configure the entry screen and optionally display rules.
   2. Enable Welcome Screen: Toggle to show/hide intro page.
   3. Button Label: Set CTA text (e.g., “Enter now”).
   4. Information & Rules Screen: Toggle to show rules.

   <Image align="center" src="https://files.readme.io/e7edd50ffa76b06e697330c8c1acb6e44398371659c4bed0d035e0d6b9cec53c-Screenshot_2025-07-22_at_12.56.52.png" />
2. **Spin Settings**
   1. Click on \*\* Add Spin \*\*to create a New Spin.
   2. Define the type and behavior of spin instances. The current version supports FREE spin with support for Paid and Quest based spins to be added soon.
   3. Additional Configure options available for the spins are
      1. Spin Type (Free or other)
      2. Animation Time (in seconds)
      3. Sections (number of wheel slices)
      4. Reset Time (spin frequency). If Never Reset option is selected, the Spin wont reset and can be hidden by integrators on the frontend.
   4. Show User Points: Toggle to display user balance on the frontend.

      1. Reward Item Link: Associate with a reward points

      <Image align="center" src="https://files.readme.io/551b9f4a1829426654fd3cb0ee68454e9b31cf4b56cd4ac9ad24edd58b37bae2-Screenshot_2025-07-22_at_12.58.07.png" />
3. **Create Products - Define the prizes users can win.**

   1. Create multiple products here that you would want to add to the Spin
   2. Each product includes details such as:
      1. Name
      2. Reward Type (None, Points, Coupon)
      3. Value (e.g., 100 points)
      4. Quantity (Unlimited, Limited)
      5. Button & URL (e.g., “Redeem Now”)
      6. Examples:
         1. Better luck next time! (No reward)
         2. Bonus Spin Points
         3. Netflix 1 Month Free – Coupon
         4. 10% Off on Domino’s – Coupon

   <Image align="center" src="https://files.readme.io/2895ef7f6e3b70cf6b3278834d08b420058b694f0f33acdf6201074c17aa631f-Screenshot_2025-07-22_at_13.00.19.png" />
4. **Sections**

   1. This is where you link product to each spin. If Multiple spins are created, select the spins from the drop down.
   2. Steps include
      1. Select Spin Type: Choose which spin to configure (e.g., Free Spin)
      2. Assign rewards to spin segments.
      3. Assign Products to Each Section (1 to N)
      4. Set Probability (Sum = 100%)

   <Image align="center" src="https://files.readme.io/b13f4976d00dce677a6241bc1e3224f1df1da41efcb8d03b37ba8c6823a6087f-Screenshot_2025-07-22_at_13.00.32.png" />
5. **Theme & Branding**

   1. Customize the visual identity of the game to match the theme and styling of your brand.
   2. Theme Selection: Use Existing, Upload, or Create New Theme
      1. The Theming provides support to upload Brand Logo, Game Logo, Sponsor Logo, change Background image or apply color and if multiple spins are consigured, each theme can have its own theming.

   <Image align="center" src="https://files.readme.io/0b70f60f1c90805c0f37f8c860bc40e87b97fb1cffeb93ed0eca236f7950d941-Screenshot_2025-07-22_at_13.00.46.png" />
6. **Schedule** - Choose launch timing: Either Publish Now or Save as Draft

   <Image align="center" src="https://files.readme.io/cab2be60c0cc77a7d5eda2c58a0f4ac9f4d6d7f6bbcee12ed8bf4d0b103b47e8-Screenshot_2025-07-22_at_13.01.03.png" />
7. **Reward History**
   1. To check the history of won items by the users, click on the three dot and click Reward History
   2. You will find all the details here.
