## Chat Room

A Chat Room is an entity that contains Users and Chat Messages. 

For more information see [https://docs.livelike.com/docs/private-group-chat](https://docs.livelike.com/docs/private-group-chat)



## Chat Session

A Chat Session represents a connection to a Chat Room. You can read and interact with a Chat Room via a Chat Session.

For more information see [https://docs.livelike.com/docs/chat-session-1](https://docs.livelike.com/docs/chat-session-1)


## Chat Configuration 

Chat Configuration represents the configurations that can be done on a chat room
For more information see [https://docs.livelike.com/docs/android-chat-config](https://docs.livelike.com/docs/android-chat-config)
