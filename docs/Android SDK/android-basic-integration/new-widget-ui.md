### Default New UI for Widgets - Version2

<Image align="center" src="https://files.readme.io/a358a01-Screenshot_2023-11-07_at_1.10.13_PM.png" />

### Integrator Usage for PopUp WidgetView

```
// UIVersion1, UIVersion2 corresponds to old and new widget stockUI

widgetView.liveLikeWidgetUiVersion=LiveLikeWidgetUiVersion.UIVersion2
```

### Integrator Usage for TimeLineView

```
val timeLineView =
    WidgetsTimeLineView(
        this,
        timeLineViewModel!!,
        engagementSDK,
        LiveLikeWidgetUiVersion.UIVersion2
    )
```
