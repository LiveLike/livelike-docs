## LiveLikeChatClient

A Chat Client is an interface that can be used to add or invite other users to a chat room.

**Features**

* Add User to a Chat Room
* Invite User to a Chat Room
* Respond to invitations
* Get List of Invitations corresponding to the User
* Create/Update Chat Room
* Get ChatRoom Details
* Get Members of Chat Room
* Delete Current User from ChatRoom
* Get Invitations Received/Sent By User
* Block/UnBlock Profile
* Get List of Block Profile
* Get Profile Mute Status
* Pin/UnPin Message
* Get List of Pin Messages

> 👍 Note
>
> The Chat Client is available from 2.4.0

> 📘 Attention
>
> All the APIs in the Engagement SDK are deprecated and will be removed in future releases.
