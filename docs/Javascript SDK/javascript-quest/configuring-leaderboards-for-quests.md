You can configure quests to update specific leaderboards when a user earns reward items. This allows for more precise control over which leaderboards are affected. If no specific leaderboards are configured, all leaderboards associated with the reward items will be updated automatically.

***

## Steps to Configure Leaderboards for Quests

## 1. Enable Leaderboards for Your Application

Reach out to your LiveLike representative to enable the leaderboard feature for your application.

## 2. Create a Quest and Enable Rewards

Once leaderboards are enabled, create a quest in the Producer Suite. Make sure to enable rewards for the quest.

## 3. Select a Reward

While setting up the quest, choose a reward item. Upon selecting a reward, you’ll see two options:

1. **Update All Leaderboards.**
2. **Update Selected Leaderboards**

## 4. Choose Leaderboards to Update

If you select Update Selected Leaderboards, a list of leaderboards linked to the reward item will appear. Choose which leaderboard(s) you’d like to update.

## 5. Save Your Configuration

Once you’ve selected the leaderboards, click Save. Your quest is now set to update only the specified leaderboards, instead of all leaderboards linked to the reward items.
