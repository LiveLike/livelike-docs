The mobile & web SDKs provide you with out-of-the-box UI and theming tools to create your own customized widget experiences. However if you're looking to dig deeper, you can build your own widget UI using our REST and Pubnub APIs. Some example use cases include:

* Custom Widget UI on any platform
* Widget UI on platforms not supported by the SDKs (eg. Tizen, Roku, etc)
* Widget UI integrated into Broadcast video or Jumbotron graphics

The tutorials listed here will show you how you can use the APIs to build these experiences.
