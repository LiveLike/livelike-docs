You can use our high latency chat feature for a cost effective solution with a tradeoff of having higher latency in receiving new messages. You can contact your LiveLike SPOC for enabling this feature.
There would be minimum of 10 second of latency in receiving new messages which is configurable for a given application.

[block:api-header]
{
  "title": "Supported Chat feature"
}
[/block]
* Sending and receiving chat messages:
     * text messages.
     * image messages.
     * custom messages.
* Delete message events.
* Chat moderation:
     * filtration of bad words.
     * muting user.
     * Shadow muting.
* hide blocked user messages.
* show unblocked user messages.
