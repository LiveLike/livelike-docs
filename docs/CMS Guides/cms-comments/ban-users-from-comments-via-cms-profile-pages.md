## Ban from comments via profile details

Banning a user from comments via their profile page is convenient when a moderator knows who to ban, but doesn't have an particular comment or report to reference before banning them.

Navigate to the profile details of the user you want to ban.

![](https://files.readme.io/4051579957f3b2d50faddc5565f83f7f79900e08b75afe780473887f3370655d-Screenshot_2025-09-11_at_12.15.33.png)

Go to bans tab, and select comment boards section (you will see all comment boards on which profile is banned).

**Unban Globally** If profile is banned globally ban globally button will have a text unban globally, and on the click it removes ban from the profile.

**Ban Globally** If you want to ban profile globally (all comment boards at once) click on ban globally button:

![](https://files.readme.io/e3b93f28b4fa9f9ed36075c8e977ee9961432ac5ca48fcca050525f169036bfb-Screenshot_2025-09-11_at_12.16.43.png)

**Ban** If you want to ban user profile on specific comment board toggle switch on the same page, then type comment board name in autocomplete input field (it is also possible multiple comment boards at once), after they are selected click on ban from comment board button.

**Unban** from specific comment board on unban button in the listed comment board:

![](https://files.readme.io/d609f4b9356182de11df36a395dc573c33f51d798313e88b49d7cbb5b53789cb-Screenshot_2025-09-11_at_12.20.36.png)
