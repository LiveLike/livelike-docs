Organization Admins can configure a default timezone for their organization via the CMS.
This allows clients to standardize timezone settings across all members without requiring every user to manually adjust their profile.

Previously, each user was responsible for setting their own timezone individually. With this feature, a single organization-wide setting ensures consistency, especially for new members.

If a user has not set their personal timezone, the timezone from their first organization is applied automatically.

**Use Cases**•

* **Simplified Setup:** When creating an organization, LiveLike Staff can set the default timezone once, removing the need for mass user adjustments.
* **Consistent Event Scheduling:** Organizations running events across multiple teams can align all members by default.
* **Better Onboarding Experience:** New members automatically adopt the organization’s timezone, minimizing confusion.
