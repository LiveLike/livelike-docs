The purpose of `useLoadStickerPacksEffect` hook is to fetch and update the sticker pack resource.

##### Example Usage:

```typescript
const { reactionPacks } = useReactionPacks({
  reactionSpaceId: "<Reaction space ID>",
});
useLoadStickerPacksEffect();
```
