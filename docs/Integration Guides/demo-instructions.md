The LiveLike Demo apps allow you to test out the SDK. To make use of them, you will need access to the Producer Suite.
[block:api-header]
{
  "type": "basic",
  "title": "iOS Demo"
}
[/block]
1. Download and install the [latest build](https://install.appcenter.ms/orgs/livelike/apps/livelike-native-ios-demo/distribution_groups/all-users-of-livelike-native-ios-demo).
2. You may need to open the Settings app and navigate to "General" -> "Profiles & Device Management" -> "LiveLike Inc" -> "Trust this developer".
3. You will be asked for an "Access Code". Enter the Program ID provided to you. (You can also [retrieve it from the Producer Suite](https://docs.livelike.com/docs/retrieving-important-keys#section-retrieving-program-id))
[block:api-header]
{
  "title": "Web Demo"
}
[/block]
1. Login to the [Producer Suite](https://cf-blast.livelikecdn.com/).
2. Open the Event Management Panel (hamburger menu on the top-left).
3. Click the vertical ellipse for your desired program.
4. Select "Open Program in Web Demo".

1. First step is to navigate to phone setting and allowing apk install from extenal sources. [More details](https://app.bitrise.io/artifact/84155038/p/ae9f4247489d10fee283c56516f29508)
2. Now open this [link](https://app.bitrise.io/artifact/84155038/p/ae9f4247489d10fee283c56516f29508) in your browser and install the apk
3. Now enter client id and program id asked on homepage
