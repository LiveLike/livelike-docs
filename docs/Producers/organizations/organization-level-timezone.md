Organization Admins can configure a timezone for their organization via the CMS. The organization's timezone will be used when a member joins and does not already have a preferred timezone configured.

## Relationship to user timezones

Times are shown in the CMS adjusted to the user's preferred timezone.

When a user joins an organization for the first time, their preferred timezone will be set to the organization's timezone.

Users can change their preferred timezone later. All of the times in the CMS will be shown in that timezone for them regardless of which organization workspace they're in.

## Setting an organization timezone

An organization's timezone is set when it is first created, and it can be changed again later when editing an organization.
