By default, the EngagementSDK components will use English (en) localized strings and does not provide additional translations for other locales. It is possible to supply translations for other locale and the EngagementSDK will prioritize those over the included translations.

The default (en) strings can be found [here](https://bitbucket.org/livelike/livelike-ios-sdk/src/master/Sources/EngagementSDK/Resources/Common/Localization/en.lproj/Localizable.strings)
