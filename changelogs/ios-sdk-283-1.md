# What's New?

* Adds `chatAutocapitalizationType` to `Theme` to support changing the autocapitalization of the message text
* Adds `quoteMenuBackgroundColor` to `Theme` to support changing the background color of quote menu action
* Adds `pageSize` parameter to `getLeaderboardEntries` to support loading more or less entries per request

# Bugfixes

* Fixes a crash caused by a race condition between initializing different instances of`EngagementSDK`
