## Whats New

* Added LiveLikeChatClient in EngagementSDK for performing all chat related APIs
* All the chat APIs in Engagement SDK are deprecated and can be used from the chat Client
* Added Pin Message Apis
* Optimised code by removing unused code and polishing some API code flows
* Expose API in ChatView to hideReactionPanel
* Added LiveLikeLeaderBoardClient in EngagementSDK containing all the leaderboard APIs 
* All the LeaderBoard APIs in Engagement SDK are deprecated and can be used from the LiveLikeLeaderBoardClient
