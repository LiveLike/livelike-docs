## What's New?

* Bug fixes to improve performance and memory management
* Introduction of end to end testing
* A way to know whether the auto claim interaction rewards is set utilizing the `getAutoclaimInteractionRewardsStatus()`  interface
* Ability to see the replies count on a comment by utilizing property `commentRepliesCount` of the `Comment` resource
