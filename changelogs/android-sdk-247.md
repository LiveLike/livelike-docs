## What's New

* Android SDK will now support min 21 SDK android version.
* Add Support for LiveLikeSDK for fetching message history and message unread count (internal changes).
* Bugfix for handling height, the width of the image in default chat stock UI
* Update user click experience for the report and block user.
* Update user click experience for reaction panel with the link in the message bubble.
* Remove app\_name from the string.xml for multiple languages
