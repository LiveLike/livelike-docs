* JSON Theme optimizations and bug fixes
* Fixed an issue where switching a content session on the `WidgetViewController` did not reset queued Widgets
* Fixed widget Alert margins to be in parity with the rest of the platforms
* Fixed a crash for muted users
* Fixed a crash for users in a producer only chat room
* Fixed a bug with reporting a user in a chatroom
