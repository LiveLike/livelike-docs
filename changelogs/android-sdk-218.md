## Whats New

* Sponsor api to fetch sponsor associated to a program
* loadInteractionHistory api exposed in widget models to get list of interactions
* Bug fix for Emoji slider vote button not changed in popup mode when timer expires
* Bug fix for vote button does not enabled in quiz after selecting a option in intractable timeline
* Bug fix for chatReaction Popup window state handling with chat item click.
* Bug fix for replacing context with applicationContext for Glide related issues (crash related with destroyed activity).
* Bug fix for auto scroll to latest message on setsession with new message event
