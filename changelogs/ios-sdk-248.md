## Whats New?

* Adds ability to fetch widgets that were created after a given date by using the new `since` parameter for the `getWidgetModels` method.  [https://docs.livelike.com/docs/accessing-widget-data#getting-widget-models](https://docs.livelike.com/docs/accessing-widget-data#getting-widget-models)
* Exposes a `clickthroughURL` on Sponsors
* Adds ability to fetch leaderboard entries for multiple profiles at a time. [https://docs.livelike.com/docs/leaderboards#getting-leaderboard-entries](https://docs.livelike.com/docs/leaderboards#getting-leaderboard-entries)
