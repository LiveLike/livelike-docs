## What's New

1. Internal upgrade of the Gradle version from 7.0.2 to 8.1.1
2. Switch to Kotlin DSL System from Grovvy System
3. Use of version catalog for dependencies handling in all modules
4. Upgrade the following 3rd party libraries to their latest version
   1. Gson 
   2. Lottie
   3. PubNub
   4. Constraint Layout
   5. Coroutines
   6. OkHtttp
5. Add a Dependency-Check Module for verifying vulnerabilities in the code.
