## What's New?

* **Widgets** - introducing the new **Number Prediction Widget**. You can now use the NumberPredictionWidgetModel and NumberPredictionFollowUpWidgetModel. Stock UI for the Number Prediction Widget will be available in the next version!
* **Chat** - an integrator now has the ability to add other users to a chat room
