Added **scrollChatToBottom** API inside **ChatView** to scroll the chat list to the bottom by the integrator\
Added **scrollToMessage** API inside **ChatView** to scroll the chat list to a particular message\
Added **allowDiscardOwnPublishedMessageInSubscription** inside **ChatSession** variable to allow the integrator to show chat message once message is sent successfully or to add a mock message in the list
