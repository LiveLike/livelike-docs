In this iOS SDK release, we offer improved and advanced sticker analytics through Mixpanel.

## Overview

We focused on improving our sticker analytics. Now clients can receive a breakdown of the highest performing stickers through a MixPanel report alongside other bugs and corrections.

## iOS 2.5.0

* Added Chat Message Displayed analytics event
* Added the WidgetViewControllerDelegate to observe Widget display and dismiss events on the WidgetViewController
* Fixed a bug where X button on Poll or Prediction widgets did not dismiss the widget
* Fixed a bug where resizing the ChatViewController changes the scroll position
