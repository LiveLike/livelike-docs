# What's New

* Add Headers as parameters to add additional headers to network API(**internal**)
* Add End2End Tests for Comments and Chats(**Internal**)

* Add getUserQuestRewards API to allow multiple userQuestIds
* Expose request API to provide support to the integrator for calling the REST API ([https://docs.livelike.com/docs/network-utils-android](https://docs.livelike.com/docs/network-utils-android))
* Add Support for Sponsors in the Widget creation APIs
* Make Origin Url as Non-Optional with a Default Value(**Internal**)
