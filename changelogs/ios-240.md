## What's New?

#### RewardsClient

* Added two new properties to the `RewardItem` object, images and attributes. [More Info](https://docs.livelike.com/docs/utilizing-reward-items#reward-item-attributes)

#### SponsorshipClient

* Added a way to specify a brand color to enable building a more uniform sponsorship experience.

#### Widgets

* Added `interactive` property to enhance widget filtering. [More Info](https://docs.livelike.com/docs/widget-framework-apis#get-widgets-by-specified-criteria) 

## Bug Fixes

#### Spoiler Prevention

* Fixed a platform parity issue where the new property `programDateAndTime` will only be set by the SDK if a video stream url is provided.
