* The snap to Live Button shows over the keyboard issue solved
* Add EndToEnd Tests for Reactions and widgets
* Add Callback to submitVote method in Poll, Quiz, ImageNumberPrediction, TextAsk Widgets
* add ResultFlow for Poll, Quiz, Prediction, and ImageNumberPrediction Widgets
