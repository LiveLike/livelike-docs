## What's New

1. Added Widget API allowing users to create the following widget.
   1. Text Poll, Image Poll
   2. Text Quiz, Image Quiz
   3. Alert
   4. TextAsk
   5. Text Prediction, Image Prediction
2. Added Widget API to allow users to publish and delete widgets.
3. BugFix for getWidgetInteractions in ContentSession to have async data fetching control.
