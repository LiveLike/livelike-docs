## Whats New?

* [Added a way to claim rewards for all the widget interactions rewards that have no been claimed](https://docs.livelike.com/docs/widget-interactions#interactions-for-which-rewards-have-not-been-claimed)
* Added support for updating poll votes across app sessions

## Bug Fixes

* Miscellaneous Default Widget UI bug fixes
* Changed the default theme `titleBackgroundColor` of CheerMeter and ImageSlider to be in parity with the rest of the platforms
* Fixed an issue where Spoiler Prevention was turned on when it should not have been
