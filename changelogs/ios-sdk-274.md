## What's New?

* Adds support for multiple reactions in Chat
* New `getSmartContracts` interface to help retrieve saves Smart Contracts for [Token Gated Chat](https://docs.livelike.com/docs/token-gating-chat)
* New ability to filter [chatroom memberships](https://docs.livelike.com/docs/ios-chat-room-membership) by user profile ID
