## What's New?

### Redemption Keys

* Three new SDK Interfaces have been added to help integrators work with Redemption Keys
* Integrators can now view redeemed keys and redeem keys by code or by key ID

### Registered Links

* Registered Links can now be added through the CMS website and associated with Badges.
* The `Badge` object now has a new property called `registeredLinks`

### Widget Attributes

* Widgets now have a new property `widgetAttributes` which can be set when sending Widgets from the CMS

### PubNub Enhancements

* Switched from the ObjC version of PubNub SDK to the Swift PubNub SDK
