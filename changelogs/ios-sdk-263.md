## Whats New?

* Snap to Live button can be [customized](https://docs.livelike.com/docs/ios-stock-chat-ui-customization) in the stock Chat UI
* Integrators can list comments with new replies - [more details](https://docs.livelike.com/docs/comment-boards)
* Comments can now be sorted by most/least recent reply  - [more details](https://docs.livelike.com/docs/comment-boards)
* Internal performance enhancements and refactoring to improve testability
