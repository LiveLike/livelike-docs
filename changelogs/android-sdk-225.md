## What's New ?

* **Widgets** - Introducing the new **Number Prediction Widget**. You can now use the NumberPredictionWidgetModel and NumberPredictionFollowUpWidgetModel. Stock UI for the Number Prediction Widget will be available in the next version!
* **Add User To ChatRoom** - Added API to allow the user to add other users to the chatroom
* **ChatRoom Alert** - Added a delegate to listen to the events when other users start a private chat with the user.

## Bug Fix

* fixed a bug related to the theming of social embed widget
