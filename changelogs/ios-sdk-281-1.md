# What's New?

* SDK Integrators can provide sponsor data when creating widgets.
* Added LLAPIHelper to expose request util to Integrators to easily use REST API.
* Internal optimisations.
* Fixed a bug that caused WidgetPopupViewController to block UI after time out dismissal.
* Integrators can now fetch multiple user quest rewards at once.
