## Redemption Keys

* Interfaces `redeemKeyByCode`, `redeemKeyById`, `getRedemptionKeys` have been added
* Integrators can view keys filtered by status and redeem keys by code or by id

## Registered Links

* Badge object has a new property called registered\_links(array of IRegisteredLink)

## Widget Attributes

* WidgetPayload has a new property widget\_attributes(array of IAttribute)
