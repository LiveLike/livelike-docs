## What's New?

* Added support for JSON themeing for Image Slider Widgets
* Added support for themeing of Submit buttons for widgets

#### RewardsClient

* Added a `RewardsClientDelegate` which an integrator can use to stay informed about received reward item transfers - [documentation](https://docs.livelike.com/docs/utilizing-reward-items#notifying-when-reward-item-transfer-is-received)
