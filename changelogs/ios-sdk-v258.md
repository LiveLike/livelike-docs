## What's New?

* Added an API function in the `ChatSession` to allow users to \[delete messages] ([https://docs.livelike.com/docs/ios-chat-session#deleting-a-message](https://docs.livelike.com/docs/ios-chat-session#deleting-a-message)) from the chat room.

* Added support to delete messages in the Stock UI. Added configurable variables `enableUserDeleteMessage` and `shouldShowDeleteConfirmation` in the `MessageViewController` to customize delete functionality in the Stock UI.
