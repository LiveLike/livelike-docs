## Whats New?

1. Add New Attributes for updating the styling of LiveLike ChatView

* add attribute to update textsize,color,font,caps,textstyle of name,message,time,reactioncount
* add attribute the define the gap factor between reaction and make it dynamically update default is 1.2 and value is in the float.
* update chat reaction panel position dynamically and add chat reaction panel gravity in attribute default is no\_gravity.\
  ([https://docs.livelike.com/docs/android-customization](https://docs.livelike.com/docs/android-customization))

2. Bugfix regarding the handling of queuing of widgets using the widgetdisplay method.
