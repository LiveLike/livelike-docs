In this Android SDK release, we empowered developers with the ability to trigger widgets without using the CMS.

## Overview

We've allowed developers the ability to manually trigger widgets. This opens up the opportunity to deep link a particular LiveLike widget, and even embed a LiveLike widget on a webpage or app screen.

## 2.4.0 Release Notes

* Added support for on demand widget instantiation
* Added support for subscribing to real-time widgets
* Added support for getting details of published widgets
* Fixed a bug with widget state handling and widget appearing sync from CMS and direct call
* Fixed a potential crash when using opening the sticker packs in a specific scenario
* Fixed a bug where the chat bubble remained selected after the message is deleted
