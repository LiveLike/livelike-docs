## Release Notes

* Introducing Token Gated (NFT) chat experience. Token gating chats allows CMS operators to control which users can enter a chat based on specific criteria, such as contract wallet address.
* Fixed bug where error was being logged when widget timeline loaded without customTemplateRenderer.
