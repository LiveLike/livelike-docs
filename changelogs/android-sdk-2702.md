## What's New

* [Social Graph Service](https://docs.livelike.com/docs/social-graph-service)
* Integrators can customize scrollbar display in Stock chat message list \[more details] ([https://docs.livelike.com/docs/stock-chat-ui-customization#customize-scrollbar-in-stock-chat-ui](https://docs.livelike.com/docs/stock-chat-ui-customization#customize-scrollbar-in-stock-chat-ui))
* Integrators can insert custom content between messages in Stock Chat UI [more details](https://docs.livelike.com/docs/stock-chat-ui-customization#insert-custom-content-between-messages-in-sock-chat-ui)
* Add default drawable to provide a separator for list items in poll, quiz, and prediction widgets.
* Add default drawable to provide background for unselected items in poll, quiz, and prediction widgets.
