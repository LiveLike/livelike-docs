## What's New?

* Users can now request for the [leaderboards](https://docs.livelike.com/docs/leaderboards#get-leaderboards-a-given-profile-is-ranked-on) a given profile is ranked on. 
* Users can filter widget interaction history using widget kind as a filter.
* Added functionality that now filters out messages from shadow muted users automatically.\
  Added a new boolean `includeFilteredChatMessages` which enables users to choose if they want to display messages that have been filtered.
