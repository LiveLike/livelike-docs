**Release Notes**:

Bugfix:

1. Image flicker in chat.
2. added JSON theme support for background in the poll, quiz, prediction, image slider, and cheer meter and update padding issue in the alert widget header.
3. Add support for filter widgets in the timeline([https://docs.livelike.com/docs/widget-timeline](https://docs.livelike.com/docs/widget-timeline)).
4. disable Lottie animation for old widgets in the timeline and support for the only real-time widget in the timeline.
