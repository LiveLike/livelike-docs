## What's New?

* Stock UI Users can upload images from the Photo Library, Camera, or the Files App in Chat Rooms.
* Reactions in a Chat Room are now supported using the LiveLike Reaction as a Service.

## Bug Fixes

* Initialization of the SDK would result in multiple calls to the Profile Resource API which now takes place only once
