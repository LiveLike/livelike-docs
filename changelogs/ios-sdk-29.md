## Whats New?

* Adds ability to subscribe to the user's rank, rank percentile, and score in a Leaderboard. [https://docs.livelike.com/docs/leaderboards#subscribe-to-the-current-users-leaderboard-position](https://docs.livelike.com/docs/leaderboards#subscribe-to-the-current-users-leaderboard-position)
* Adds ability to see which Rewards Items can be earned on a Program
* Adds ability to override where/how the user's Prediction votes are persisted. [https://docs.livelike.com/docs/rewards#prediction-widgets](https://docs.livelike.com/docs/rewards#prediction-widgets)

## Bug Fixes

* Fix widget timers freezing when app is backgrounded
* Fix visual issue with the Sticker keyboard when changing device orientation
* Fix GIFs in Chat messages on iOS 14
* Fix compilation error in Xcode 12
