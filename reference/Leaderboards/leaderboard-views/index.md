Leaderboard Views provide a way to efficiently group and query for only a subset of profile entries on a large Leaderboard.  Some common use-cases include:

* A single Global leaderboard with regional views for North America, Europe, Asia, and others.
* A League leaderboard with views for fans of different teams.

A leaderboard can have any number of views, and any number of user profiles can be added to a view.  The same profile may be added to multiple views.  This allows for a wide range of flexible options to show a customized view of a large leaderboard.
